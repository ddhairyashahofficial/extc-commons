# EXTC Commons
Open-source academic resource hub for engineering students.
This repository contains:
* Lecture PPTs
* Subject PYQs
* Class Notes
* Lab Experiments

# Structure
```text
year-branch/
└── sem-subject/
    ├── README.md        # How to study & Resource links
    ├── syllabus-subject
    ├── doc-subject
    └── ppt-subject
```

# Contribution
Contributions are welcome.

# Goal
To build a simple, organized, and community-driven academic resource platform for core engineering students.
