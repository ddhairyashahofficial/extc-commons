# EXTC Commons

Open academic resource hub for engineering students.
This repository contains:
* Lecture PPTs
* Subject PYQs
* Class Notes
* Lab Experiments

# Structure

```text
year-branch/
└── sem-subject/
    ├── README.md      # How to study & Resource links
    ├── syllabus-subject
    ├── doc-subject    # IA & ISE scheme, PYQs and other materials
    ├── ppt-subject    # Theory
    └── num-subject    # Numericals

eg:
sy-extc/
├── sem3/
└── Sem4/
```

## Repository Guidelines

- Maintain the existing folder structure.
- Use descriptive filenames.
- Avoid duplicate uploads.
- Prefer PDF format where possible.
- Verify resources before uploading.
